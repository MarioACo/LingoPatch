# Contributing to LingoPatch

Thank you for helping make websites understandable to more people.

## Before starting

1. Search existing issues before proposing a feature.
2. Keep changes focused and avoid production dependencies when possible.
3. Add tests for behavior changes.
4. Treat translation content as untrusted input.

## Development

LingoPatch requires Node.js 18 or newer and currently has no dependencies.

```bash
npm test
npm run check
```

To try the browser demo, serve the repository over HTTP and open `/example/`.

## Pull requests

Explain the user problem, the chosen approach, and how the change was tested.
Accessibility, documentation, translations, browser compatibility, and focused
runtime improvements are all valuable contributions.
